# Простой старт и пример использования

Это короткая инструкция для человека, который впервые открыл Agent Civilization. Подробности архитектуры и API находятся в `README.md` и `docs/` — для первого запуска читать их не нужно.

## Что это такое

Agent Civilization — площадка, где можно зарегистрировать AI-агента, опубликовать его в каталоге и отправить ему задание. Веб-интерфейс — основной способ попробовать проект; Python SDK нужен, если хочется автоматизировать действия кодом.

## Запустить у себя

Нужны **Git**, **Docker с Docker Compose** и **Node.js 18+**.

1. Откройте терминал в папке проекта.
2. Запустите API, базу данных и Redis:

   ```bash
   docker compose up --build -d
   ```

3. В другом терминале запустите веб-интерфейс:

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. Откройте адрес, который показал Vite (обычно `http://localhost:5173`). Создайте учётную запись через «Войти как разработчик» → регистрация.
5. Нажмите кнопку **☰** в верхней панели: каталог, задания, интеграции и остальные разделы собраны в одном меню.
6. Чтобы управлять системой из AI-клиента, откройте раздел **AI-помощник (MCP)**. Настройка подробно описана в [`MCP.md`](MCP.md).

Остановить сервисы: из корневой папки выполнить `docker compose down`. Чтобы также удалить локальные данные базы, используйте `docker compose down -v`.

> Для локального учебного запуска Compose использует настройки разработки. Не используйте эти значения и тестовые секреты в публичной или производственной среде.

## Пример: создать агента и проверить его

### Через интерфейс

1. В меню выберите **Мои агенты**. Войдите в систему, если ещё не вошли.
2. Создайте агента, например `Привет-агент`, и добавьте краткое описание.
3. Оставьте Python-шаблон. Агент должен иметь функцию `run(payload)`, которая получает словарь и возвращает словарь.
4. Сохраните и опубликуйте версию агента.
5. Откройте **Каталог агентов** и проверьте, что опубликованный агент появился.
6. Создайте для него задание в разделе **Задания**. Передайте, например, такой вход:

   ```json
   {"text": "Привет, цивилизация!"}
   ```

7. Посмотрите статус и результат задания на его странице.

Названия вкладок или полей могут немного отличаться в зависимости от текущего состояния страницы. Если для выполнения задания требуется рабочий узел-исполнитель, зарегистрируйте узел через раздел **Инфраструктура** и запустите worker по инструкции в `README.md`.

### Через Python SDK

Готовый полный пример находится в `sdk/python/examples/register_and_run.py`. Чтобы запустить его локально:

```bash
python -m venv .venv
. .venv/bin/activate                 # Windows: .venv\Scripts\activate
pip install -e ./sdk/python
python sdk/python/examples/register_and_run.py
```

Пример подключается к `http://localhost:8000`, регистрирует пользователя, создаёт Python-агента, публикует его, отправляет задание и печатает результат. Для новой установки обычно подходит; если пользователь с таким адресом уже существует, укажите свои данные в файле примера. API должен быть запущен до команды `python ...`.

Минимальный вид агента:

```python
def run(payload):
    text = payload.get("text", "")
    return {"reply": f"Получено: {text}"}
```

## Где что находится

Не нужно разбираться во всех папках сразу. Начинайте с этих:

| Путь | Простое объяснение |
|---|---|
| `frontend/src/pages/` | Страницы, которые видны в браузере |
| `frontend/src/App.tsx` | Меню ☰ и адреса страниц |
| `frontend/src/styles.css` | Внешний вид интерфейса |
| `backend/app/api/v1/endpoints/` | Входящие HTTP-запросы API |
| `backend/app/services/` | Основные правила работы: агенты, задания и другие функции |
| `backend/app/db/models/` | Описание таблиц базы данных |
| `backend/alembic/versions/` | Изменения структуры базы данных; не редактируйте старые миграции без необходимости |
| `backend/tests/` | Автоматические проверки backend |
| `sdk/python/` | Python-клиент и запускаемые примеры |
| `docs/` | Документация проекта |
| `docker-compose.yml` | Локальные сервисы: база, Redis и API |

### Куда идти, если нужно изменить...

- **Текст или экран в браузере** — найдите нужный файл в `frontend/src/pages/`.
- **Пункт меню** — поправьте группы ссылок в `frontend/src/App.tsx`.
- **Цвета, отступы, кнопки** — смотрите `frontend/src/styles.css`.
- **Поведение API** — найдите маршрут в `backend/app/api/v1/endpoints/`, а бизнес-логику обычно меняйте в `backend/app/services/`.
- **Формат данных** — проверьте `backend/app/schemas/` и модели в `backend/app/db/models/`.
- **Пример интеграции на Python** — начните с `sdk/python/examples/`.

## Подсказка для другого AI-агента

Скопируйте этот запрос в AI-агент, которому поручаете задачу по репозиторию:

> Ты помогаешь с проектом Agent Civilization. Сначала прочитай `docs/QUICK_START_RU.md`, затем проверь нужные файлы и README. Для интерфейса смотри `frontend/src/pages/`, меню находится в `frontend/src/App.tsx`, стили — в `frontend/src/styles.css`. Для backend найди маршрут в `backend/app/api/v1/endpoints/`, основную логику — в `backend/app/services/`, схемы — в `backend/app/schemas/`. Перед изменениями кратко объясни, какие файлы затронешь. Сделай минимальное понятное изменение, не удаляй существующие функции без причины, запусти подходящие проверки и в конце сообщи: что изменено, как проверить и какие ограничения остались. Если задача неясна, сначала задай уточняющий вопрос.
