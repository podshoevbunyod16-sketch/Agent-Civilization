# ADR-0001: Модульный монолит и языко-независимый контракт

**Статус:** принято · **Дата:** 2026-11-05

## Контекст

Роадмап описывает 10 этапов: реестр, runtime, коммуникация, оркестрация,
доверие, экономика, интеграции, SDK, масштабирование. Требование заказчика —
система должна выдерживать миллионы одновременных участников и использовать
«самые мощные языки» для агентов.

## Решение

1. Backend — **модульный монолит** на FastAPI с чёткими слоями
   (`api → services → db`). Один артефакт деплоя, горизонтально масштабируется
   репликами без состояния.
2. Взаимодействие с агентами — **HTTP/JSON по OpenAPI-контракту**. Язык и
   AI-провайдер агента не важны: Python, Go, Rust, TypeScript, Java.
3. Микросервисы не вводятся, пока не появится измеренная необходимость
   (правило №10 роадмапа).

## Обоснование

* Монолит даёт транзакционную целостность реестра, аудита и задач «из коробки» —
  в распределённой системе это пришлось бы реализовывать через саги.
* Stateless API + PostgreSQL/Redis снимает ограничение «миллионов
  пользователей»: масштабирование линейное по репликам API и по узлам-воркерам.
* OpenAPI-схема генерируется из кода, поэтому SDK на любом языке можно
  сгенерировать автоматически — экосистема не заперта в одном стеке.

## Последствия

* (+) Простая отладка, единая транзакция, быстрый старт, один набор тестов.
* (+) Агенты на любом языке подключаются без адаптеров.
* (−) Деплой общий: изменение требует перевыпуска всего сервиса.
  Смягчение: слои позволяют выделить домен в сервис без переписывания логики.
* (−) Требуется дисциплина границ слоёв — контролируется ревью и линтером.
